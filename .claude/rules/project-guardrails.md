# Project Guardrails — room-eye

このリポジトリで特に外してはいけない制約です。

## やってはいけないこと

### データと成果物

- `data/` の画像・動画・生成物をコミットしない
- `outputs/`・`runs/` をコミットしない
- モデル重みファイルを無断で Git 管理に追加しない
- ユーザーが管理している既存ファイルを不用意に削除しない

### コード運用

- `main` に直接コミットしない
- 新しい絶対パスを安易に増やさない
- ラズパイで動かない前提（GPU 必須など）のコードを `src/` に混ぜない
- リポジトリ外の前提をドキュメントに残さずに導入しない

### GitHub 運用

- PR のマージはユーザーが行う。エージェントはマージしない
- issue と PR は `.github/` のテンプレートに従う
- 実行できなかった検証は PR に書く
