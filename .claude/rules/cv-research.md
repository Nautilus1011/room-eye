# CV Research Rules — room-eye

## データ管理

- `data/` 配下の画像・動画・アノテーションは原則 Git に含めない
- `outputs/`・`runs/` などの実行結果はコミットしない
- モデル重みファイル（`.pt`・`.onnx` 等）は新規に Git 管理に追加しない
- データ仕様・クラス定義・前処理の変更は issue またはドキュメントに残す

---

## モデル選定

- ラズパイ（ARM64 CPU のみ）での実用速度を常に意識する
- 新しいモデルを試す場合は、まず CPU での推論速度を計測してから採用を判断する
- ONNX エクスポートの可否を確認してから実装に組み込む

---

## 推論・実験

- 比較実験では、ベースライン条件を固定してから差分を 1 つずつ増やす
- 推論速度・精度・消費メモリを明記する
- 小規模サンプルで動作確認してから本番データに適用する

---

## ノートブック

- 探索・可視化は `experiment/` 内の Jupyter ノートブックで行い、再利用するロジックは `src/` に移植する
- ノートブックのセルは上から順に実行して再現できる状態に保つ
- 大きなデータや学習済みモデルをノートブック内に直接保存しない

---

## 再現性

- モデルのバージョン・推論パラメータ（conf_thres・iou_thres 等）を明記する
- 絶対パスを増やさず、設定ファイルに寄せる
- 重い実験を省略した場合も、再現に必要な前提（データ、環境、パラメータ）を書き残す
