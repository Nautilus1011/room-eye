## 書き方

- ファイル名は `NNNN-kebab-case-title.md`（4 桁ゼロ埋めの連番）
- 構成: `## 背景` / `## 決定` / `## 理由` / `## 結果と影響` / `## 再検討する条件`
- ステータスは `提案` / `採用` / `棄却` / `置換済み` のいずれか

## 追記専用のルール

**既存の ADR は書き換えない。** 判断を覆すときは以下の手順を踏む。

1. 新しい番号の ADR を追加し、`## 背景` で旧 ADR を参照する
2. 旧 ADR のステータスを `置換済み` に変更し、本文冒頭に新 ADR へのリンクを追記する
3. この索引の両方の行を更新する

判断が変わった経緯そのものが情報なので、履歴を消さずに残す。
